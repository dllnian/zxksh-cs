# 执行可视化大屏系统

这是一个专业的法院执行案件可视化大屏系统，采用1920x1080分辨率设计，蓝色系配色方案。

## 功能特点

### 数据展示模块
1. **案件收结存情况** - 实时展示新收、旧存、已结案件数据及趋势
2. **执行标的到位率** - 环形进度图展示执行标的完成情况
3. **失信被执行人分布** - 地理分布热力图展示
4. **案款情况** - 提存案款和未发还案款统计
5. **执行质效指标** - 多维度质效指标达标情况
6. **执行工作态势** - 日/周/月趋势分析
7. **执行难点定位** - 主要执行难点问题分析

### 设计特点
- **蓝色系主题** - 专业、科技感的视觉设计
- **响应式动画** - 流畅的数据更新和交互动画
- **实时数据更新** - 自动刷新显示最新数据
- **图表可视化** - 使用ECharts实现丰富的图表展示

## 快速查看

1. 直接在浏览器中打开 `execution-visualization.html` 文件
2. 建议使用Chrome、Firefox等现代浏览器
3. 最佳显示效果为1920x1080分辨率全屏模式

## 技术栈

- HTML5 + CSS3
- JavaScript (原生)
- ECharts 5.4.3 (数据可视化)
- 渐变色彩和动画效果

## 注意事项

- 本系统为演示原型，实际部署需要连接真实数据接口
- 地图组件使用了模拟效果，实际使用需要集成真实地图服务
- 数据更新间隔可根据需求调整

## 界面预览

系统采用三列布局：
- **左侧面板**：案件统计和执行标的信息
- **中间面板**：地图展示和趋势分析
- **右侧面板**：案款情况、质效指标和难点分析

整体设计简洁大气，信息层次清晰，适合在指挥中心、会议室等场景使用。
