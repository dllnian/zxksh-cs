# 执行可视化大屏系统

## 项目概述

这是一个法院执行案件数据可视化大屏系统，用于整合展示执行案件数据，分析展示执行案件新收、旧存、已结等收结存情况、执行标的到位率、失信被执行人分布等关键指标。通过可视化图表展示执行质效指标的区间达标情况和执行工作态势，定位执行难点，为执行工作决策提供支撑。

## 设计规格

- **分辨率**: 1920×1080
- **配色方案**: 蓝色系科技风格
- **主题**: 执行可视化

## 功能模块

### 1. 案件收结存分析
- 本月新收案件数及趋势
- 旧存案件数及变化
- 本月已结案件数及趋势
- 收结存流向趋势图

### 2. 失信被执行人分布
- 地域分布可视化
- 密度热力展示
- 重点区域标注

### 3. 核心执行指标
- 执行到位率
- 执行标的总额
- 结案率
- 平均执行用时

### 4. 执行工作态势
- 执行案件数趋势
- 到位金额变化
- 到位率走势

### 5. 执行质效指标
- 有财产可供执行案件法定期限内结案率
- 终本案件合格率
- 执行信访办结率
- 执行案款发放及时率
- 执行到位率
- 首次执行案件结案率

### 6. 案款管理
- 提存案款情况
- 未发还案款情况
- 案款流转分析

### 7. 执行难点定位
- 被执行人下落不明
- 无可供执行财产
- 财产难以处置
- 案外人异议
- 协助执行难

## 技术栈

- HTML5
- CSS3 (含动画效果)
- JavaScript
- ECharts 5.4 (数据可视化)

## 使用说明

1. 在浏览器中打开 `index.html` 查看大屏效果
2. 推荐使用 1920×1080 分辨率查看最佳效果
3. 支持 Chrome、Firefox、Safari、Edge 等现代浏览器

## 特色功能

- **实时数据更新**: 模拟实时数据变化，展示动态效果
- **响应式图表**: 所有图表支持窗口大小调整
- **视觉效果**: 渐变色彩、动画过渡、阴影效果
- **交互体验**: 鼠标悬停高亮、数据提示框
